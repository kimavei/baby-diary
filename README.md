# Baby Diary — rich daily edition library

This package is a replacement for the current Baby Diary website files. It preserves the existing calendar and due-date mapping, while changing the article panel to a richer magazine-style briefing.

## Files
- `index.html` — calendar, due-date selector, English/Lithuanian selector, magazine article layout.
- `content-library.json` — 281 day indices (0+0 through 40+0) in English and Lithuanian, with weekly development context, daily focus, nutrition, research-literacy topic, practical Lithuania reminder, birth/newborn preparation, checklist, quiz, and source links.
- `assets/` — locally stored illustrative images used at the beginning of each article.

## Publish to GitHub Pages
1. Download and unzip this package.
2. Back up your current repository files.
3. Open https://github.com/kimavei/baby-diary
4. Upload/replace `index.html` and `content-library.json` at the repository root.
5. Upload the entire `assets` folder so the image paths exist as `assets/pregnancy-home.jpg`, `assets/nutrition-bowl.jpg`, and `assets/newborn-sleep.jpg`.
6. Commit directly to `main`.
7. Wait for GitHub Pages to deploy, then hard-refresh https://kimavei.github.io/baby-diary/ (Cmd+Shift+R on Mac).

Do not upload the contents into a nested second `baby-diary` folder. The root should contain `index.html`, `content-library.json`, and `assets/`.

## Important content note
This is a prepared educational library, not a live medical or legal service. The 280+ date entries are generated from 40 stage-specific development entries and rotating daily themes, with varied daily actions, research-literacy topics, and practical prompts. They are not 280 independently peer-reviewed medical research articles. Check linked official sources for current Lithuanian benefit rules and ask a clinician for personal medical advice. Photo files are local illustrative images cropped from an AI-generated concept mockup; they are not documentary photographs of actual patients.


## Expanded editorial content
The expanded library includes a date-specific entry for each index from 0+0 through 40+0 in English and Lithuanian. Each entry includes stage context, development text, wellbeing, nutrition, a distinct practical focus, research-literacy explanation, Lithuania-specific official-source reminder, newborn/birth preparation, question for the care team, quiz, checklist, longer reading section and practical plan.

This is a general-education library, not 562 independently peer-reviewed research articles. It avoids hard-coding benefit amounts that may become outdated. Official links are provided for verification; users should confirm current rules and discuss personal care with a clinician.
